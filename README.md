# 🧪 Muonic Hydrogen Simulation

**Simulation:** https://share.gemini.google/qwqUgcbQb4GS

An interactive simulation demonstrating the formation and decay of **muonic hydrogen**.

## How to Use

1. Click **`Turn On Particle Accelerator`** to generate a pion.
2. Wait for the pion to **decay into a muon**.
3. Click **`Turn On Solenoid`**.
4. Click **`Bring Muon to Solenoid`** to transfer and accelerate the muon.
5. **Time the collision** so the muon reaches the hydrogen atom correctly.
6. If successful, the muon **replaces the electron** and begins orbiting the proton.
7. Wait for the muon to **decay**. The electron will return to its orbit.

### Simulation Flow

`Pion → Muon → Solenoid → Hydrogen → Muonic Hydrogen → Muon Decay → Electron Returns`
